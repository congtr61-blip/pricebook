# Pricebook 需求文档

当前版本：**v3.0（已完成）**

## v1.0（已完成）
- [x] 商户登录，查看商品价格和库存
- [x] 管理员编辑商品/库存
- [x] 管理员为每个商户设置专属价格和标签

## v2.0（已完成）
- [x] 商户按数量直接下单，填写提货时间和备注
- [x] 下单时原子扣减库存，库存不足时拒绝下单
- [x] 商户查看订单、状态、下单时间和提货时间
- [x] 商户只能取消待确认订单，取消时自动回退库存
- [x] 管理员查看订单，并确认或取消订单
- [x] 已确认订单可由管理员取消并回退库存，已取消订单不可重复操作
- [x] 订单状态清晰显示：待确认、已确认、已取消
- [x] 订单列表默认折叠，点击后展开详情；已取消订单使用删除线显示
- [x] 营业时间和公告功能，管理员编辑、商户查看
- [x] 客户留言系统，支持商户和管理员查看及发送留言
- [x] 订单、留言日期使用固定时区格式，避免页面 hydration 错误
- [x] 兼容手机屏幕展示


## v3.0（已完成）
- [x] 优化页面，现在看起来有点粗糙
- [x] 输入框、日期选择和客户备注输入更友好
- [x] 中英文切换按钮及核心页面文案切换
- [x] 商户电话维护、订单备注录入，管理员订单详情展示商户标签和电话
